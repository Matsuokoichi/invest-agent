# Vision

市場価格を短期予測するAIではなく、企業の経済性、将来cash flow、本源的価値、市場価格の差を調べ、投資仮説を継続的に構築・反証・更新するInvestment Research Agentを作る。

V1はFundamental / Long-onlyの米国株リサーチに限定する。良い企業の発見ではなく、現在価格でリスクに見合う期待リターンとmargin of safetyがあるかを、検証可能な証拠と計算で判断する。

最終成果物は、FACT / ESTIMATE / INFERENCEを分離した引用付きレポート、再現可能なvaluation、BUY / WATCH / AVOID判定、Thesis invalidation条件である。自動売買と個人向け投資助言は目的に含めない。

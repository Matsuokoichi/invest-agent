# Architecture Decision Records

ADRs record durable architectural choices that are costly or unsafe to infer from current code. Use sequential names such as `0001-context-governance.md`.

Each ADR states its status, context, decision, consequences, and superseded decisions. Do not use ADRs for temporary implementation status or routine code changes.
